Lecture 12

Stabilizer codes

Lecture 11 gave the exact condition for correcting errors, a matrix of numbers for every pair of errors. This lecture asks: how do commuting Paulis define a code, and which errors does it correct? A stabilizer code is the space fixed by commuting Pauli operators; with rrr independent generators on nnn qubits it has dimension 2n−r2^{n-r}2n−r (Theorem 12.3). Its syndromes are bits, read off from commutation, and a set of Pauli errors is correctable if no Ej†EkE_j^\dagger E_kEj†​Ek​ commutes with the code’s group without acting on the code as a number (Theorem 12.6, the main result). Steane’s code is the worked example: [[7,1,3]]\nkd{7}{1}{3}[[7,1,3]].

By the end of this lecture you will be able to:

  • Multiply Pauli operators with their phases, decide whether two commute, and compute the syndrome of a Pauli error.
  • Prove that a stabilizer group with rrr independent generators on nnn qubits has a code of dimension 2n−r2^{n-r}2n−r.
  • Prove that Pauli errors with no Ej†EkE_j^\dagger E_kEj†​Ek​ in N(S)∖⟨i1⟩S\Norm{S}\setminus\langle i\Id\rangle SN(S)∖⟨i1⟩S are correctable, and that a code of distance 2t+12t+12t+1 corrects every error on ttt qubits.
  • Verify from its six generators that Steane’s code is [[7,1,3]]\nkd{7}{1}{3}[[7,1,3]].

12.1 The Pauli group

Lectures 10 and 11 used products such as Z1Z2Z_1Z_2Z1​Z2​, X1⋯X6X_1\cdots X_6X1​⋯X6​ and Yi=iXiZiY_i=iX_iZ_iYi​=iXi​Zi​. With phases allowed, they form a group.

Definition 12.1 (The Pauli group). The Pauli group Gn\Pauli{n}Gn​ consists of the matrices cP1⊗⋯⊗PncP_1\otimes\cdots\otimes P_ncP1​⊗⋯⊗Pn​ with c∈{±1,±i}c\in\{\pm1,\pm i\}c∈{±1,±i} and each Pq∈{1,X,Y,Z}P_q\in\{\Id,X,Y,Z\}Pq​∈{1,X,Y,Z}. The weight wt⁡(E)\wt(E)wt(E) of such an EEE is the number of qqq with Pq≠1P_q\neq\IdPq​=1. We write P1⋯PnP_1\cdots P_nP1​⋯Pn​ for the product without its phase: IIXZIIXZIIXZ is X3Z4X_3Z_4X3​Z4​, of weight 2.

By XY=iZXY=iZXY=iZ, YZ=iXYZ=iXYZ=iX, ZX=iYZX=iYZX=iY and YX=−iZYX=-iZYX=−iZ (the Pauli relations σaσb=δab1+iεabcσc\sigma_a\sigma_b=\delta_{ab}\Id+i\varepsilon_{abc}\sigma_cσa​σb​=δab​1+iεabc​σc​), the product of two elements of Gn\Pauli{n}Gn​ is in Gn\Pauli{n}Gn​, computed qubit by qubit; the phases ±1,±i\pm1,\pm i±1,±i are what make it closed. Each Pauli string P1⊗⋯⊗PnP_1\otimes\cdots\otimes P_nP1​⊗⋯⊗Pn​ is self-adjoint and squares to 1\Id1, so (cP)2=c21(cP)^{2}=c^{2}\Id(cP)2=c21: an element of Gn\Pauli{n}Gn​ squares to 1\Id1 if its phase is ±1\pm1±1, and then it is self-adjoint, and to −1-\Id−1 if its phase is ±i\pm i±i.

12.2 Stabilizers, code space, dimension

Definition 12.2 (Stabilizer code). A stabilizer group is a subgroup SSS of Gn\Pauli{n}Gn​ whose elements commute and which does not contain −1-\Id−1. Generators g1,…,grg_1,\dots,g_rg1​,…,gr​ of SSS (every element is a product of them) are independent if none is a product of the others. The stabilizer code C(S)C(S)C(S) is the set of vectors ψ\psiψ with gψ=ψg\psi=\psigψ=ψ for every g∈Sg\in Sg∈S; ΠC\Proj_CΠC​ is its projector.

A vector fixed by the generators is fixed by their products, so C(S)C(S)C(S) is the common +1+1+1 eigenspace of g1,…,grg_1,\dots,g_rg1​,…,gr​. As −1∉S-\Id\notin S−1∈/S, no element of SSS has the phase ±i\pm i±i, since its square would be −1-\Id−1: every g∈Sg\in Sg∈S has g2=1g^{2}=\Idg2=1 and is self-adjoint, and ±i1∉S\pm i\Id\notin S±i1∈/S. The eight observables of Shor’s code (§10.4) generate a stabilizer group: they commute, and a product of some of them that uses an XXX-product has an XXX or a YYY somewhere (the two XXX-products multiply to X1X2X3X7X8X9X_1X_2X_3X_7X_8X_9X1​X2​X3​X7​X8​X9​), and one that uses only ZZZ-pairs has a ZZZ (the two pairs of a block multiply to Z1Z3Z_1Z_3Z1​Z3​, and so on); so it is ±1\pm\Id±1 only if it uses none.

Theorem 12.3 (Dimension). Let g1,…,grg_1,\dots,g_rg1​,…,gr​ be independent generators of a stabilizer group S⊆GnS\subseteq\Pauli{n}S⊆Gn​. Then ΠC=∏j=1r12(1+gj),\Proj_C=\textstyle\prod_{j=1}^{r}\tfrac12(\Id+g_j),ΠC​=∏j=1r​21​(1+gj​), and C(S)C(S)C(S) has dimension 2n−r2^{n-r}2n−r.

Proof. Each 12(1+gj)\tfrac12(\Id+g_j)21​(1+gj​) is the projector onto the +1+1+1 eigenspace of gjg_jgj​, as gjg_jgj​ is self-adjoint with gj2=1g_j^{2}=\Idgj2​=1, and they commute; so their product is the projector onto the common +1+1+1 eigenspace, which is C(S)C(S)C(S). Expanding the product, ΠC=2−r∑a∈{0,1}rg1a1⋯grar.\Proj_C=2^{-r}\textstyle\sum_{a\in\{0,1\}^{r}}g_1^{a_1}\cdots g_r^{a_r}.ΠC​=2−r∑a∈{0,1}r​g1a1​​⋯grar​​. For a≠0a\neq0a=0, ga=g1a1⋯grarg^{a}=g_1^{a_1}\cdots g_r^{a_r}ga=g1a1​​⋯grar​​ is in SSS, so it is ±P\pm P±P for a Pauli string PPP. If PPP were 1\Id1, then gag^{a}ga would be −1-\Id−1, which SSS does not contain, or 1\Id1, which makes each gjg_jgj​ with aj=1a_j=1aj​=1 the product of the others, as gj−1=gjg_j^{-1}=g_jgj−1​=gj​. So P≠1P\neq\IdP=1, and Tr⁡P=∏qTr⁡Pq=0\Tr P=\prod_q\Tr P_q=0TrP=∏q​TrPq​=0, as Tr⁡X=Tr⁡Y=Tr⁡Z=0\Tr X=\Tr Y=\Tr Z=0TrX=TrY=TrZ=0. Hence dim⁡C(S)=Tr⁡ΠC=2−rTr⁡1=2n−r\dim C(S)=\Tr\Proj_C=2^{-r}\Tr\Id=2^{n-r}dimC(S)=TrΠC​=2−rTr1=2n−r. 

So nnn qubits and rrr independent generators encode k=n−rk=n-rk=n−r qubits; for Shor’s code n=9n=9n=9, r=8r=8r=8 and k=1k=1k=1, the plane of ∣0L⟩\ket{0_L}∣0L​⟩ and ∣1L⟩\ket{1_L}∣1L​⟩. Both hypotheses bite. ⟨Z,−Z⟩\langle Z,-Z\rangle⟨Z,−Z⟩ on one qubit contains −1-\Id−1 and fixes no vector but 000, and the dependent Z1Z2Z_1Z_2Z1​Z2​, Z2Z3Z_2Z_3Z2​Z3​, Z1Z3Z_1Z_3Z1​Z3​ fix the plane of the bit-flip code, of dimension 222, not 23−32^{3-3}23−3. The proof is Watrous’s (2025, pp. 420–421); Nielsen and Chuang prove it otherwise (Proposition 10.5, p. 458).

12.3 Syndromes

An error E∈GnE\in\Pauli{n}E∈Gn​ commutes or anticommutes with each generator. 12.4 Distance; correctability

Write ⟨i1⟩S\langle i\Id\rangle S⟨i1⟩S for the set of cgcgcg with c∈{±1,±i}c\in\{\pm1,\pm i\}c∈{±1,±i} and g∈Sg\in Sg∈S.

The elements of N(S)∖⟨i1⟩S\Norm{S}\setminus\langle i\Id\rangle SN(S)∖⟨i1⟩S are the logical errors: invisible to the syndrome, and harmful on the code.

Definition 12.5 (Distance). The distance ddd of a stabilizer code is the least weight of an element of N(S)∖⟨i1⟩S\Norm{S}\setminus\langle i\Id\rangle SN(S)∖⟨i1⟩S, if it has one. A code of nnn qubits, dimension 2k2^{k}2k and distance ddd is an [[n,k,d]]\nkd{n}{k}{d}[[n,k,d]] code.

Nielsen and Chuang (p. 467) take the least weight in N(S)−S\Norm{S}-SN(S)−S, which contains −1-\Id−1, of weight 000; removing the phases ±1\pm1±1, ±i\pm i±i, as ⟨i1⟩S\langle i\Id\rangle S⟨i1⟩S does, mends it.

Theorem 12.6 (Correctable Pauli errors). Let SSS have independent generators, and let E1,…,Em∈GnE_1,\dots,E_m\in\Pauli{n}E1​,…,Em​∈Gn​. If no Ej†EkE_j^\dagger E_kEj†​Ek​ lies in N(S)∖⟨i1⟩S\Norm{S}\setminus\langle i\Id\rangle SN(S)∖⟨i1⟩S, then some recovery corrects E1,…,EmE_1,\dots,E_mE1​,…,Em​ on C(S)C(S)C(S).

Proof. Each Ej†EkE_j^\dagger E_kEj†​Ek​ is in Gn\Pauli{n}Gn​. So the condition of Theorem 11.2 holds. 

Two errors may share a syndrome: Ej†Ek∈SE_j^\dagger E_k\in SEj†​Ek​∈S is allowed, as for Z1Z_1Z1​ and Z2Z_2Z2​ on Shor’s code, where Z1Z2∈SZ_1Z_2\in SZ1​Z2​∈S. Nielsen and Chuang’s Theorem 10.8 (p. 466) asks Ej†Ek∉N(S)−SE_j^\dagger E_k\notin\Norm{S}-SEj†​Ek​∈/N(S)−S, which also excludes pairs such as X1X_1X1​ and −X1-X_1−X1​, whose product −1-\Id−1 meets the condition of Theorem 11.2.

12.5 Steane’s code

Steane’s code has seven qubits and the six generators (Nielsen and Chuang, Fig. 10.6, p. 456, qubit 1 on the left) g1=IIIXXXX,g4=IIIZZZZ,g2=IXXIIXX,g5=IZZIIZZ,g3=XIXIXIX,g6=ZIZIZIZ.\begin{aligned} g_1&=IIIXXXX, & g_4&=IIIZZZZ,\\ g_2&=IXXIIXX, & g_5&=IZZIIZZ,\\ g_3&=XIXIXIX, & g_6&=ZIZIZIZ. \end{aligned}g1​g2​g3​​=IIIXXXX,=IXXIIXX,=XIXIXIX,​g4​g5​g6​​=IIIZZZZ,=IZZIIZZ,=ZIZIZIZ.​ Qubit iii carries an XXX in g1g_1g1​, g2g_2g2​, g3g_3g3​, and a ZZZ in g4g_4g4​, g5g_5g5​, g6g_6g6​, according to the binary digits of iii, the first generator for the digit 444. An XXX-type and a ZZZ-type generator share 222 or 444 qubits, so all six commute. Qubits 444, 222 and 111 carry an XXX in g1g_1g1​, g2g_2g2​, g3g_3g3​ alone and a ZZZ in g4g_4g4​, g5g_5g5​, g6g_6g6​ alone, so a nonempty product has an XXX, YYY or ZZZ on one of them, as XZ=−iYXZ=-iYXZ=−iY. So no nonempty product is ±1\pm\Id±1: the generators are independent and −1∉S-\Id\notin S−1∈/S. By Theorem 12.3 the code has dimension 27−6=22^{7-6}=227−6=2: k=1k=1k=1.

Summary

  • The Pauli group: phases ±1,±i\pm1,\pm i±1,±i; two elements commute or anticommute, by the parity of the qubits where both are not 1\Id1 and differ; weight.
  • Stabilizer codes: rrr independent commuting generators with −1∉S-\Id\notin S−1∈/S fix a code of dimension 2n−r2^{n-r}2n−r (Theorem 12.3).
  • Syndromes: bits by anticommutation; they add, and vanish exactly on N(S)\Norm{S}N(S).
  • The main result: if no Ej†EkE_j^\dagger E_kEj†​Ek​ lies in N(S)∖⟨i1⟩S\Norm{S}\setminus\langle i\Id\rangle SN(S)∖⟨i1⟩S, the Pauli errors are correctable (Theorem 12.6); distance 2t+12t+12t+1 corrects every error on ttt qubits (Corollary 12.7).
  • Steane: [[7,1,3]]\nkd{7}{1}{3}[[7,1,3]], from its six generators.
