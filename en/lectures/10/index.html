Lecture 10

Errors and the first codes

What this lecture does

Lecture 9 closed the second answer with gates that never err. This lecture opens the third block, protection, and asks: can a qubit be protected without copying it? Noise is a gate on the system and an environment that is then discarded (Theorem 10.2). The bit-flip code corrects one flipped qubit without copying (Theorem 10.4). The main result: Shor’s nine-qubit code corrects every one-qubit error, as its syndrome measurement collapses a continuous error onto a discrete one (Theorem 10.6).

By the end of this lecture you will be able to:

  • Derive the Kraus operators of noise from a gate on the system and an environment in a fixed state, and show that a correlated start gives no map of the system’s state alone.
  • Prove that the bit-flip code corrects one flipped qubit, compute its failure probability 3p2−2p33p^{2}-2p^{3}3p2−2p3 under independent flips, and show that under independent phase flips with 0<p<120<p<\tfrac120<p<21​ it does worse than no code.
  • Prove that Shor’s code corrects every noise whose Kraus operators each act on one qubit, and say how its syndrome measurement makes a continuous error discrete.

Example 10.7 (A small rotation). Let the error be a rotation of qubit 1, e−iϵ n⋅σ/2=cos⁡(ϵ/2)1−isin⁡(ϵ/2) n⋅σe^{-i\epsilon\,n\cdot\sigma/2}=\cos(\epsilon/2)\Id-i\sin(\epsilon/2)\,n\cdot\sigmae−iϵn⋅σ/2=cos(ϵ/2)1−isin(ϵ/2)n⋅σ, with n⋅σ=nxX1+nyY1+nzZ1n\cdot\sigma=n_xX_1+n_yY_1+n_zZ_1n⋅σ=nx​X1​+ny​Y1​+nz​Z1​ for a unit vector nnn: one Kraus operator. On ψ\psiψ in the code, the syndrome measurement gives the syndrome of 1\Id1 with probability cos⁡2(ϵ/2)\cos^{2}(\epsilon/2)cos2(ϵ/2), and those of X1X_1X1​, Y1Y_1Y1​, Z1Z_1Z1​ with probabilities nx2n_x^{2}nx2​, ny2n_y^{2}ny2​, nz2n_z^{2}nz2​ times sin⁡2(ϵ/2)\sin^{2}(\epsilon/2)sin2(ϵ/2). It leaves ψ\psiψ, X1ψX_1\psiX1​ψ, Y1ψY_1\psiY1​ψ or Z1ψZ_1\psiZ1​ψ, each up to a global phase, and the correction returns ψ\psiψ up to that phase. For ϵ=0.1\epsilon=0.1ϵ=0.1, a whole error occurs with probability sin⁡2(0.05)≈0.0025\sin^{2}(0.05)\approx0.0025sin2(0.05)≈0.0025.

The rotation is continuous, the syndrome discrete. The measurement never finds a fraction of an error: it finds none, or a whole one, and leaves a state that one of the 28 corrections repairs. This is how the syndrome measurement collapses a continuous error onto a discrete one, and why correcting 28 errors protects against a continuum: the proof of (ii) used only that each KkK_kKk​ is a combination of the 28. Lecture 11 finds the exact condition under which a code corrects a set of errors, and proves that its recovery then corrects every linear combination of them.

Protection is not perfection. Two errors can defeat the code: X1X2X_1X_2X1​X2​ has the syndrome of X3X_3X3​, and the correction leaves X1X2X3X_1X_2X_3X1​X2​X3​, which fixes ∣0L⟩\ket{0_L}∣0L​⟩ and reverses the sign of ∣1L⟩\ket{1_L}∣1L​⟩. And the encoding, the syndrome circuit and the corrections were taken to be exact; Lecture 13 states what survives when they too are noisy.

So a qubit can be protected without copying it: the code spreads it over nine qubits, and the syndrome measurement asks only which error occurred, a question whose answer says nothing about the state.

Summary

  • Noise: a gate on the system and an environment in a fixed state, which is then discarded, acts as ρ↦∑KρK†\rho\mapsto\sum K\rho K^\daggerρ↦∑KρK† with ∑K†K=1\sum K^\dagger K=\Id∑K†K=1 (Theorem 10.2); a correlated start gives no map of ρ\rhoρ alone.
  • The bit-flip code: two CNOTs encode without copying; the syndrome locates one flip and reveals nothing about the state; under independent flips the code fails with probability 3p2−2p33p^{2}-2p^{3}3p2−2p3 (Theorem 10.4), and under independent phase flips with 0<p<120<p<\tfrac120<p<21​ more often than no code.
  • The main result: Shor’s code corrects every noise whose Kraus operators each act on one qubit; its syndrome measurement collapses a continuous error onto one of 28 (Theorem 10.6).
