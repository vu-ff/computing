Lecture 11

When is an error correctable?

What this lecture does

Lecture 10 protected a qubit against every one-qubit error, with a recovery built for Shor’s code. This lecture asks: which errors can a code correct? The answer is one condition on the code and the errors, Knill and Laflamme’s: if ΠCEi†EjΠC=αijΠC\Proj_CE_i^\dagger E_j\Proj_C=\alpha_{ij}\Proj_CΠC​Ei†​Ej​ΠC​=αij​ΠC​ for numbers αij\alpha_{ij}αij​, a recovery exists (Theorem 11.2, the main result; the converse is cited). A recovery that corrects a set of errors undoes every noise whose Kraus operators are combinations of them (Theorem 11.5), Lecture 10’s discrete collapse in general.

By the end of this lecture you will be able to:

  • State the Knill–Laflamme condition, prove that it gives a recovery that corrects the errors, and state its converse with its source.
  • Prove that a recovery that corrects a set of errors undoes every noise whose Kraus operators are linear combinations of them.
  • Compute the Knill–Laflamme matrix of the bit-flip code and of Shor’s code for their errors, and say when a code is degenerate.

11.1 Recovery as a channel

In Lecture 10 a recovery measured a syndrome and applied a correction. Averaged over the outcome it is R(τ)=∑sCsΠsτΠsCs†\mathcal R(\tau)=\sum_sC_s\Proj_s\tau\Proj_sC_s^\daggerR(τ)=∑s​Cs​Πs​τΠs​Cs†​: a map with the Kraus operators Rs=CsΠsR_s=C_s\Proj_sRs​=Cs​Πs​, and ∑sRs†Rs=∑sΠs=1\sum_sR_s^\dagger R_s=\sum_s\Proj_s=\Id∑s​Rs†​Rs​=∑s​Πs​=1. 11.2 KL sufficiency

Theorem 11.2 (Knill–Laflamme). Let CCC be a code and E1,…,EmE_1,\dots,E_mE1​,…,Em​ errors. If there are numbers αij\alpha_{ij}αij​ with ΠCEi†EjΠC=αijΠC\Proj_CE_i^\dagger E_j\Proj_C=\alpha_{ij}\Proj_CΠC​Ei†​Ej​ΠC​=αij​ΠC​ for all iii and jjj, then some recovery corrects E1,…,EmE_1,\dots,E_mE1​,…,Em​ on CCC.

The condition says that the errors move every code vector alike: ⟨Eiφ|Ejψ⟩=αij⟨φ|ψ⟩\braket{E_i\varphi}{E_j\psi}=\alpha_{ij}\braket{\varphi}{\psi}⟨Ei​φ∣Ej​ψ⟩=αij​⟨φ∣ψ⟩ for all φ\varphiφ, ψ\psiψ in CCC. The proof turns the errors into combinations that take CCC to mutually orthogonal copies of itself, and undoes each copy.

11.3 The converse

Theorem 11.4 (The converse cited). If a recovery R\mathcal RR has R(N(ρ))=ρ\mathcal R(\mathcal N(\rho))=\rhoR(N(ρ))=ρ for every density operator ρ\rhoρ on CCC, for a noise N(τ)=∑iEiτEi†\mathcal N(\tau)=\sum_iE_i\tau E_i^\daggerN(τ)=∑i​Ei​τEi†​ with ∑iEi†Ei=1\sum_iE_i^\dagger E_i=\Id∑i​Ei†​Ei​=1, it corrects E1,…,EmE_1,\dots,E_mE1​,…,Em​, and so they meet the condition of Theorem 11.2.

It rests on a theorem on Kraus operators not proved here (Nielsen and Chuang, Theorem 8.2 and pp. 437–438; Knill and Laflamme, p. 14).

11.4 Discretisation

Theorem 11.5 (Discretisation). Let a recovery R\mathcal RR correct E1,…,EmE_1,\dots,E_mE1​,…,Em​ on CCC. Then it corrects every linear combination of them, and every noise N(τ)=∑kKkτKk†\mathcal N(\tau)=\sum_kK_k\tau K_k^\daggerN(τ)=∑k​Kk​τKk†​, ∑kKk†Kk=1\sum_kK_k^\dagger K_k=\Id∑k​Kk†​Kk​=1, whose KkK_kKk​ are linear combinations of the EiE_iEi​ has R(N(ρ))=ρ\mathcal R(\mathcal N(\rho))=\rhoR(N(ρ))=ρ for every density operator ρ\rhoρ on CCC.

Proof. For K=∑iciEiK=\sum_ic_iE_iK=∑i​ci​Ei​, RlKΠC=∑iciλliΠCR_lK\Proj_C=\sum_ic_i\lambda_{li}\Proj_CRl​KΠC​=∑i​ci​λli​ΠC​. So for the noise RlKkΠC=μlkΠCR_lK_k\Proj_C=\mu_{lk}\Proj_CRl​Kk​ΠC​=μlk​ΠC​ with numbers μlk\mu_{lk}μlk​, and as ρ=ΠCρΠC\rho=\Proj_C\rho\Proj_Cρ=ΠC​ρΠC​, R(N(ρ))=∑l,k∣μlk∣2ρ.\mathcal R(\mathcal N(\rho))=\textstyle\sum_{l,k}\abs{\mu_{lk}}^{2}\rho .R(N(ρ))=∑l,k​∣μlk​∣2ρ. Both maps keep the trace, so the sum is Tr⁡ρ=1\Tr\rho=1Trρ=1, as in the proof of Theorem 10.6. 

With Theorem 11.2, a code that meets the condition for finitely many errors is protected against every noise whose Kraus operators lie in their span: a continuum. For Shor’s code and its 28 errors this is Theorem 10.6(ii), since every 2×22\times22×2 matrix is a combination of 1\Id1, XXX, YYY, ZZZ. Nielsen and Chuang’s Theorem 10.2 (p. 438) states it for the recovery their proof constructs; here it holds for every recovery that corrects the errors. A recovery known only to undo one noise corrects its Kraus operators by Theorem 11.4, and then every combination of them.

11.5 R’s matrix

For the bit-flip code and the errors 1\Id1, X1X_1X1​, X2X_2X2​, X3X_3X3​: if i≠ji\neq ji=j, Ei†EjE_i^\dagger E_jEi†​Ej​ flips one or two bits of 000000000 and of 111111111, taking CCC to a subspace orthogonal to it, so ΠCEi†EjΠC=0\Proj_CE_i^\dagger E_j\Proj_C=0ΠC​Ei†​Ej​ΠC​=0; and Ei†Ei=1E_i^\dagger E_i=\IdEi†​Ei​=1. So α=1\alpha=\Idα=1, every dk=1d_k=1dk​=1, and with u=1u=\Idu=1 the construction has Fk=EkF_k=E_kFk​=Ek​ and Πk=EkΠCEk\Proj_k=E_k\Proj_CE_kΠk​=Ek​ΠC​Ek​, the four syndrome projectors of Lecture 10, which add up to 1\Id1: Π⊥=0\Proj_\perp=0Π⊥​=0. 11.6 The degenerate guard

Shor’s code meets the condition for its 28 errors, as its recovery corrects them (§11.1). Two errors with different syndromes have αij=0\alpha_{ij}=0αij​=0, as they take CCC into orthogonal syndrome spaces. Not so Z1Z_1Z1​ and Z2Z_2Z2​: Z1Z2Z_1Z_2Z1​Z2​ fixes every code vector (§10.4), so ΠCZ1†Z2ΠC=ΠC\Proj_CZ_1^\dagger Z_2\Proj_C=\Proj_CΠC​Z1†​Z2​ΠC​=ΠC​, and for these two errors α=(1111),\alpha=\begin{pmatrix}1&1\\1&1\end{pmatrix},α=(11​11​), which is singular: (Z1−Z2)ΠC=0(Z_1-Z_2)\Proj_C=0(Z1​−Z2​)ΠC​=0. A code is degenerate for a set of errors if α\alphaα is singular (Gottesman, p. 14): some combination of the errors annihilates the code, here because two errors act alike on it. Example 11.3 shows the construction dropping that combination.

For the 28 errors, α\alphaα is 111 off the diagonal exactly for ZiZ_iZi​ and ZjZ_jZj​ in one block; it has rank 22, and six zero eigenvalues. The construction of Theorem 11.2 drops those six directions, as FkΠC=0F_k\Proj_C=0Fk​ΠC​=0 there, and keeps 22 copies of CCC, as many as Lecture 10 has syndromes. Degeneracy costs nothing: the recovery need not tell Z1Z_1Z1​ from Z2Z_2Z2​, since they act alike. A classical code, by contrast, tells errors on different bits apart (Nielsen and Chuang, p. 444).

For subsets of these 28 errors, α\alphaα is singular exactly when it is not diagonal: an entry 111 off the diagonal means that two errors act alike, and their difference annihilates CCC. In general neither implies the other: on the bit-flip code {X1,X1+X2}\{X_1,X_1+X_2\}{X1​,X1​+X2​} has α=(1112)\alpha=\left(\begin{smallmatrix}1&1\\1&2\end{smallmatrix}\right)α=(11​12​), not diagonal and invertible, and on Shor’s code {1,Z1−Z2}\{\Id,Z_1-Z_2\}{1,Z1​−Z2​} has α=diag(1,0)\alpha=\mathrm{diag}(1,0)α=diag(1,0), diagonal and singular. Lecture 12 lets two errors that act alike share a syndrome.

Summary

  • Recovery: a map with Kraus operators RlR_lRl​, ∑lRl†Rl=1\sum_lR_l^\dagger R_l=\Id∑l​Rl†​Rl​=1; it corrects E1,…,EmE_1,\dots,E_mE1​,…,Em​ on CCC if RlEiΠC=λliΠCR_lE_i\Proj_C=\lambda_{li}\Proj_CRl​Ei​ΠC​=λli​ΠC​ (Definition 11.1).
  • The main result: if ΠCEi†EjΠC=αijΠC\Proj_CE_i^\dagger E_j\Proj_C=\alpha_{ij}\Proj_CΠC​Ei†​Ej​ΠC​=αij​ΠC​, some recovery corrects the errors (Theorem 11.2); a recovery that undoes a noise forces the condition on its Kraus operators (Theorem 11.4, cited).
  • Discretisation: a recovery that corrects a set of errors undoes every noise whose Kraus operators are combinations of them (Theorem 11.5).
  • R: α=1\alpha=\Idα=1 for 1\Id1, X1X_1X1​, X2X_2X2​, X3X_3X3​, and the construction is Lecture 10’s recovery; independent flips, 0<p<10<p<10<p<1, are not correctable.
  • Degenerate: for Z1Z_1Z1​, Z2Z_2Z2​ on Shor’s code α\alphaα is singular; the recovery corrects both.
