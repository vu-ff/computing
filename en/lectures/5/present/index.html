Lecture 5

Questions to an oracle

Lecture 2 solved Deutsch’s problem with one query, which one classical query cannot. This lecture asks: can a quantum algorithm learn about a function with exponentially fewer questions? It fixes the query model and its classical competitor, and answers yes for Simon’s problem: n+2n+2n+2 queries decide whether a hidden string sss is zero (Theorem 5.6, the main result), where every classical algorithm needs of the order of 2n/22^{n/2}2n/2 (Theorem 5.9, cited). The separation is proved, and relative to an oracle.

By the end of this lecture you will be able to:

  • Define the query model, and show on Deutsch–Jozsa’s problem why a count of queries must name its competitor.
  • Show that garbage which tells branches apart destroys their interference, and that constant garbage changes nothing.
  • Compute the Hadamard transform by cancellation, and prove that Simon’s circuit returns a uniform yyy with y⋅s=0y\cdot s=0y⋅s=0, and that n+2n+2n+2 runs decide whether s=0s=0s=0.
  • State the classical Ω(2n/2)\Omega(2^{n/2})Ω(2n/2) bound with its idea, and the status of the separation.

5.1 The query model

Definition 2.5 made the oracle Uf\UfUf​ of a function and called each use of it a query. To compare algorithms by their queries, both sides of the comparison must be fixed.

Definition 5.1 (The query model). A problem in the query model is a set F\mathcal{F}F of functions f ⁣:{0,1}n→{0,1}mf\colon\{0,1\}^{n}\to\{0,1\}^{m}f:{0,1}n→{0,1}m, the promise, and a property of fff to be decided.

  • A quantum query algorithm is a procedure (§3.3) in which fff enters only through Uf\UfUf​, applied to n+mn+mn+m of its qubits.

  • A classical query algorithm chooses strings xxx, each from the answers before it and from random bits, and receives f(x)f(x)f(x).

The cost is the largest number of queries, uses of Uf\UfUf​ or strings chosen, over all runs and all f∈Ff\in\mathcal{F}f∈F. An algorithm decides the property exactly if it answers correctly with probability 111 for every f∈Ff\in\mathcal{F}f∈F, and with bounded error if it does so with probability at least 23\tfrac2332​ for every f∈Ff\in\mathcal{F}f∈F.

Everything but the queries is free: gates, readings, and any computation between queries. The model asks how much must be learned about fff, not how hard it is to compute with what was learned, and in it lower bounds can be proved (§5.6).

The competitor must be named. In Deutsch–Jozsa’s problem, f ⁣:{0,1}n→{0,1}f\colon\{0,1\}^{n}\to\{0,1\}f:{0,1}n→{0,1} is promised to be constant or balanced, equal to 111 on exactly half of the 2n2^{n}2n strings, and the task is to decide which. One quantum query decides it exactly (Example 5.4). An exact classical algorithm needs 2n−1+12^{n-1}+12n−1+1 queries on the constant 000: a run that stops after at most 2n−12^{n-1}2n−1 answers 000 gets the same answers, with the same random bits, from a balanced function that is 000 on every string asked, and gives it the same verdict. Against exact algorithms the gap is exponential. With bounded error it is not: ask three independent uniform strings, and say “constant” if the three values agree. A constant fff always passes, and a balanced fff gives three equal values with probability 2⋅(12)3=142\cdot(\tfrac12)^{3}=\tfrac142⋅(21​)3=41​; so three queries succeed with probability at least 34\tfrac3443​ for every fff, whatever nnn. The two-query test of de Wolf (p. 19) and Watrous (p. 142) errs with probability 12\tfrac1221​ on a balanced fff; two suffice if, when the values agree, “constant” is said only with probability 23\tfrac2332​. From here on, fewer queries means fewer than a classical algorithm with bounded error needs.

5.6 The classical bound

A classical algorithm learns that s≠0s\neq0s=0 from a collision: two queried strings x≠x′x\neq x'x=x′ with f(x)=f(x′)f(x)=f(x')f(x)=f(x′), and then s=x⊕x′s=x\oplus x's=x⊕x′.

Theorem 5.9 (Simon’s classical bound cited). There is a constant c>0c>0c>0 such that every classical query algorithm that decides Simon’s problem with bounded error makes at least c 2n/2c\,2^{n/2}c2n/2 queries.

The proof is de Wolf’s (§3.3.2, pp. 25–26), for this decision version. Kitaev, Shen and Vyalyi (Prop. 13.1, pp. 117–118) state it for finding sss, with a constant: at most 2n/22^{n/2}2n/2 queries err with probability above 13\tfrac1331​ for some fff (their kkk is our nnn, and p. 118 prints the denominator 2(2k−1−1)2(2^{k-1}-1)2(2k−1−1) for 2(2k−1)2(2^{k}-1)2(2k−1)). The idea, for sss and fff chosen at random: until two queries collide, the answers are distinct strings that look the same whether s=0s=0s=0 or not. And T<2n/2T<2^{n/2}T<2n/2 queries collide with probability at most T2/2nT^{2}/2^{n}T2/2n, since a new xxx collides only if sss is one of the fewer than TTT strings x⊕x′x\oplus x'x⊕x′ with x′x'x′ asked before, while sss is still spread over about 2n2^{n}2n candidates. Against the n+2n+2n+2 queries of Theorem 5.6, the gap is exponential.

5.7 Status

Theorems 5.6 and 5.9 compare numbers of queries, and the comparison has a status:

  • it is proved: both bounds are theorems, the classical one for every algorithm, however much it computes between queries;

  • it is relative to an oracle: both sides see fff only through its oracle;

  • it says nothing about BPP\BPPBPP versus BQP\BQPBQP, the decision problems that classical and quantum computers solve efficiently with bounded error (Lecture 6). A problem given by a circuit for fff, rather than by its oracle, hands a classical algorithm the circuit itself, and the lower bound no longer applies.

De Wolf (pp. 17 and 25) stresses that the separation is of queries, not of operations in the circuit model. Relative to suitable oracles BPP\BPPBPP and BQP\BQPBQP are known to differ, while without an oracle no separation is known (Watrous 2008, p. 18); Lecture 6 says why a proof would be hard.

Summary

  • The query model counts queries against a named competitor: Deutsch–Jozsa takes one quantum query, 2n−1+12^{n-1}+12n−1+1 exact classical ones, but at most three with bounded error (Definition 5.1 and Example 5.4).
  • The guard: garbage left alone destroys the interference between the branches it tells apart, and only those (Example 5.2).
  • The main result: each run of Simon’s circuit, Fourier sampling on Z2n\Z_2^{n}Z2n​, returns a uniform yyy with y⋅s=0y\cdot s=0y⋅s=0, and n+2n+2n+2 runs with the rank test decide whether s=0s=0s=0 (Theorem 5.6). Classically Ω(2n/2)\Omega(2^{n/2})Ω(2n/2) queries are needed (Theorem 5.9, cited): a separation proved, relative to an oracle.
